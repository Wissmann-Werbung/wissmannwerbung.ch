# wissmannwerbung.ch

Statische Webseite für **WISSMANN.WERBUNG** – Full-Service Werbe- und
Marketing-Agentur, Hintergass 20, 8424 Embrach.

## Struktur

```
index.html        Startseite (Agentur, Leistungen, Arbeitsweise, Kontakt)
impressum.html    Impressum
datenschutz.html  Datenschutzerklärung
css/style.css     Stylesheet
js/main.js        Mobile-Navigation & Footer-Jahr
img/favicon.svg   Favicon
```

## Verwendung

Reines HTML/CSS/JS ohne Build-Schritt – die Dateien können direkt auf einen
beliebigen Webserver oder ein statisches Hosting (z. B. GitHub Pages, Netlify)
geladen werden.

Lokal ansehen:

```bash
python3 -m http.server 8000
# dann http://localhost:8000 öffnen
```
